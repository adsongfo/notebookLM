# notebookLM
Esse é um notebook que fiz para poder treinar meus conhecimento com treinamento de inteligência artificial, usando a ferramenta do google Notebook LM inseri algumas fontes das quais achei interessante para ajudar a praticar meus conhecimentos com o treinamento de IA e também usar a ferramenta para auxiliar meu estudo na linguagem Python
Como fonte de informação para IA conseguir cumprir seu propósito, adicionei inicialmente 9 fontes para que ela retirasse seu conhecimento, três ebooks de guia para iniciar em Python, explicando coisas básicas de iniciante como a historia da linguagem, como funciona listas, operadores, Tuplas, strings, valores boleanos e assim por diante. O restante das fontes foram playlists de cursos disponibilizados no Youtube do canal curso em vídeo com o Gustavo Guanabara. Escolhi os vídeos do Gustavo pois foi com ele minha primeira interação com a progamação e admiro o trabalho dele, considero ele um bom professor, irei desponibilizar o pdf dos três ebooks que utilizei como fonte e os vídeos podem ser encontrados facilmente no Youtube.
